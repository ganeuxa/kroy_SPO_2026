## Запуск

```bash
QA_NGINX=1 .venv/bin/python -m pytest tests/pytest/stage3 --run-ops -v
QA_NGINX=1 .venv/bin/python -m pytest tests/pytest/stage3 -m smoke -v
```

Нужен подготовленный локальный QA-стенд и учебная учётная запись администратора.
Тесты создают пользователей, заказы и собственные товары; товары скрываются после
проверки. Запускать последовательно, только на учебном QA-стенде.
Локальные протоколы: qa-results/stage3.txt и stage3.xml (не коммитятся).
